Frequently Asked Questions // quick answers
How do I get a Groq API key for the AI chatbot?

Go to console.groq.com, create a free account, and generate an API key. Then open any page's source JS and replace YOUR_GROQ_API_KEY with your actual key. The Llama 3.3 70B model is free to use within Groq's rate limits.

The AI chatbot is not responding — what should I do?

First check that your Groq API key is correctly set in the source file. If you're using the default placeholder key, it will not work. Also check the browser console (F12) for error messages. If the error is rate-limit related, wait a minute and try again.

Can I use this website's code for my own projects?

Yes! This is an open learning platform. You're welcome to study and adapt the code for personal projects. Please give credit if you use large sections. For commercial use, reach out first via Telegram or GitHub.

How do I report a bug or broken feature?

Use the contact form below and select "Bug Report" as the type. Include the page name, what you expected to happen, and what actually happened. Screenshots are very helpful. You can also open a GitHub issue.

How do I request a new tutorial or code example?

Send a message on Telegram (@alonemonster20) or fill out the form below with "Feature Request" selected. Popular requests will be prioritised for the next Codes article or YouTube video.

How do I log in or create an account?

Visit the Login page. You can sign in with Google or create an account with email. Your profile saves your learning progress and preferences.
